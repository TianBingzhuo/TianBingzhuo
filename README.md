# Tian Bingzhuo / 田秉卓

Hi, I'm Bingzhuo — an applied physics undergrad at Hebei University of Technology, expecting my B.S. in 2027.

Most of my time goes to things where code has to meet the physical world: embedded boards, motors, sensors, optical instruments, displays. Over the past couple of years I've worked through a rescue robot system on Raspberry Pi 5, the hardware platform for a national smart-car vision competition, a digitally-upgraded Young's modulus measurement instrument with a C# / WinUI 3 host app, and an 8051 course project that I turned into a small pixel desktop buddy as a design exercise beyond the base assignment. I also founded the AI Innovation Club at my university and have been volunteering with the OpenCamp open-source community.

I'm interested in operating systems, embedded systems, robotics system software, ROS 2/DDS, and real-time control-chain latency, especially problems where the hardware and software stack have to be considered together.

## 关于这些仓库

这些仓库大部分来自课程、竞赛或者团队项目。我尽量让公开版本保持诚实而不是精致：能帮人看懂项目的代码和工程推理都留着；私人记录和没有确认来源的第三方材料不放进来；队友的贡献都标明出处，不会悄悄算到自己头上。

总之：这些仓库尽量保持可读、可追溯，也保留真实课程和竞赛项目里难免存在的粗糙边角。

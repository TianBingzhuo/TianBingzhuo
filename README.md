## Documentation Style

These repositories are public engineering archives rather than raw file dumps. I try to keep each project readable by separating:

- what the project is for;
- what is included in the public repository;
- what my contribution was;
- what teammates contributed;
- what third-party or private materials are intentionally not mirrored.

这些项目都来自团队协作或竞赛场景。公开仓库会尽量保留工程链路、代码和复盘价值，同时避免上传未授权的第三方工具、私人材料、原始结果数据或未经队友确认的内容。
